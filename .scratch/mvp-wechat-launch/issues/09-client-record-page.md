# 09: 记录页（原型 03）

**What to build:** 真正干活的那一页。按原型 03：顶部 7 天日期条 + 可跳任意日期的日期选择器 + 类型筛选（全部 / 喂奶 / 辅食 / 睡眠 / 排便 / 尿布）+ 当日时间线 + 点按编辑 + ＋添加。

切换日期后看到的是**那一天**的时间线，而不是全部记录，这样补记昨天的事才顺手。筛选与日期选择可叠加；筛选到某一类但没有记录时是「还没有这类记录」的空状态，不是一片空白。日期过滤按 spec 的决定走客户端本地日期（不给记录列表接口加 `from` / `to` 参数），这是明确接受的取舍。

记录的十类新增、编辑保存、删除后底部撤销、语音 / 拍照草稿确认后才进时间线、媒体播放与预览都已存在于搬过来的实现里，本票要把它们收进新的页面结构并补齐状态与适老要求。这一页的照护者可能是爷爷奶奶辈，因此日期条与筛选条的点击区必须够大（≥48px 高）、文字够大。

**Blocked by:** 06（页面骨架与搬迁后的记录页由 06 交付）

**Status:** ready-for-agent

- [ ] 顶部有 7 天日期条，并能通过日期选择器跳到任意一天
- [ ] 切换日期后时间线只显示那一天（按客户端本地日期过滤），筛选与日期选择可叠加
- [ ] 类型筛选覆盖全部 / 喂奶 / 辅食 / 睡眠 / 排便 / 尿布
- [ ] 筛选到某一类且无记录时显示「还没有这类记录」的空状态
- [ ] 点时间线任意一条进入编辑，保存后列表与首页今日指标同步更新
- [ ]＋按钮可新增十类记录（喂奶、辅食、睡眠、排便、尿布、哭闹、身高体重、疫苗、用药、自定义）
- [ ] 语音或拍照生成的是待确认草稿，确认后才成为记录，不直接进时间线
- [ ] 识别未配置或失败时仍给出可手动填写的草稿，且上传的语音 / 照片不丢失
- [ ] 删除一条记录后页面底部立刻可撤销
- [ ] 记录里的语音可播放、照片可预览，且鉴权之后仍能正常打开
- [ ] 加载中 / 加载失败 / 无数据三种状态都有明确中文提示
- [ ] 日期条与筛选条点击区高度 ≥48px，文字可读性满足适老要求
- [ ] `npm run typecheck`、`npm test`、`npm run build:h5` 通过
