# 02 真实语音和图片识别验收

Status: ready-for-human

## 影响与证据

本轮新增识别链路已通过服务替身测试，但未调用付费 ASR / 大模型。替身测试证明流程、校验和幂等行为，不能证明真实模型在老人语速、口音、噪声和模糊照片下的准确率。也未判断现有凭证是否有效。

## 已完成的处理

沿用已有 provider 配置与凭证变量，未复制或输出密钥；补充结构化提取格式、上下文和时区，服务端校验必要字段，信息不清楚时追问。提供失败重试并复用已上传媒体，保留明确的未保存状态，不显示虚假成功。

## 人工验收样例

- 明确说出奶量；只说“刚喝了奶”后再回答“120 毫升”；“昨天晚上八点喝了 150 毫升”。
- 拍奶瓶、辅食及无法辨认的照片。照片不能证明实际已吃/已用时，应询问实际事件；看不清的量不得猜测。
- 非记录内容、静音、噪声和口音；预期不硬凑业务记录，允许重新说、重新拍或补充。
- 服务断网、超时或配置不可用时，预期显示失败并允许重试，不误报成功。

## 下一步

在运营者确认真实服务调用与费用范围后，用少量已获授权的样本验收 ASR、视觉提取和时间解析；失败时记录脱敏 request_id、输入类型、预期和实际结果。不得把本轮本地检查标成真实识别验收完成。
