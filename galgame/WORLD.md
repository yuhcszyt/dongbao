# 世界设定

虚构娱乐工业世界。现实公众人物姓名与公开气质仅作锚点；私人剧情全部属于本游戏虚构世界。

## 公司

见 `company/company.json`。

默认公司名：**星衡影业**（可在存档中改名）。

业务：电影、电视剧、综艺、品牌商务、艺人经纪。

轻量状态（服务剧情，不是复杂模拟器）：

```yaml
company:
  name:
  cash:
  reputation:          # 0-100
  industry_influence:  # 0-100
  active_projects:
  signed_artists:
  employees:
```

典型剧情钩子：资金紧张、新片选女主、档期冲突、品牌临时换人、票房失利、艺人爆红、舆情、竞争公司挖人。

## 玩家

```yaml
player:
```

## 角色槽位

第一位核心角色：**刘浩存**（`skills/liu-haocun/`）

```yaml
liu_haocun:
  identity: 公司旗下重点女演员
  relationship_with_player: 老板与旗下艺人
  relationship_stage: S0
  affection: 0
  trust: 5
  comfort: 0
```

以后可新增：其他现实女演员、虚构女演员、经纪人、制片人、导演、公司员工、竞争公司人物。

每人必须有完整字段（见 `skills/characters/_template/profile.md`）。  
**不要**把所有女角色写成自动喜欢玩家。

## 多角色关系网

角色之间可有：合作、朋友、陌生、竞争、不喜欢、欣赏、误会、和解。

禁止所有角色只围着玩家转。即使玩家不参与，她们之间的事件也可继续发生，并写入存档。
