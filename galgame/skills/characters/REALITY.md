# 现实人物规则（新增女星必读）

适用于所有**对应现实公众人物**的角色卡。虚构角色标 `fiction: true` 后可放宽私设，但仍须成年。

## 硬规则

1. **先搜再写**：新建或复活角色前，用公开搜索核对近 3–12 个月活动、在拍/待播作品、访谈语气。
2. **每个真人角色必须有 `anchors.md`**：只写可溯源公开事实；每条尽量带出处类型（报道/访谈/官宣）。
3. **事业状态跟新闻走**：`current_project` / 存档里的在拍项目不得用完全瞎编的主线电影顶替已有公开片单（游戏可加「星衡侧会议/合作提案」，但公开履历要并存且可辨认）。
4. **说话方式跟访谈走**：从公开采访提炼节奏与用词习惯；禁止写成通用甜妹/霸总女主。
5. **私人剧情一律标注虚构**：恋爱、私下住址、未公开恋情、真实联系方式 — 禁止写成现实事实。
6. **更新习惯**：用户说「继续」且角色长期未更新时，先刷新 `anchors.md` 近况再开演。

## 新增女星步骤

1. 复制 `galgame/skills/characters/_template/` → `galgame/skills/<slug>/`
2. 先写 `anchors.md`（公开时间线 + 语料），写不满就先搜够再填 profile
3. 再写 `profile.md` / `speech.md` / `relationships.md` / `scenarios.md`
4. 登记 `WORLD.md`、`saves/current.json`、相关角色关系网
5. 若与刘浩存等同场：更新双方 `relationships.md`，关系类型要合理（同事/竞争/陌生…），禁止开局全员恋玩家

## 搜索清单（最低）

- `[姓名] 2025|2026 作品|开机|定档|访谈`
- `[姓名] 专访 采访`（提炼说话方式）
- 近两个月：红毯、杂志、商务官宣、舆情（只作背景，不猎奇私生活）

## 与游戏公司 AU 的关系

- 玩家公司（星衡影业）是**虚构经营层**
- 现实经纪公司/工作室名称可写在 `anchors.md`，不要假装玩家公司就是现实中的那家
- 游戏里「签约/重点合作」是 AU；公开作品名、档期、获奖与访谈语气必须可对齐现实
