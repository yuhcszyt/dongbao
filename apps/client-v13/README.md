# 懂宝 1.3 · 微信小程序前端（真实接口版）

以 `docs/prooduct/dongbao-interactive-prototype1.3.html` 的布局和交互为依据，使用 uni-app / Vue 3 / TypeScript。小程序优先，保留 H5。新增工程位于 `apps/client-v13`，不会覆盖旧客户端。

## 安装、构建与导入

从仓库根目录运行：

```bash
npm ci --prefix apps/client-v13
make test-client CLIENT_DIR=apps/client-v13
npm run build:mp-weixin --prefix apps/client-v13
npm run build:h5 --prefix apps/client-v13
```

微信开发者工具导入 `apps/client-v13`，其中 `project.config.json` 指向 `dist/build/mp-weixin/`。AppID 沿用原客户端 `wxddfd2a5610b90fec`。若账号没有该 AppID 权限，用户须替换 `src/manifest.json` 和 `project.config.json` 中的 AppID。

需要用户自行启用源码监听时，执行 `npm run dev:mp-weixin --prefix apps/client-v13`，导入 `dist/dev/mp-weixin/`。Agent 不启动前端开发服务器、不打开浏览器／开发者工具／GUI、不截图。

## 后端地址

- 默认后端端口 **8001**。小程序构建自动选择本机局域网 IPv4，写入绝对 `/api/v1` 地址；手机与服务端须在同一局域网。
- H5 开发端口 5174，通过 Vite 将 `/api` 代理到 `http://127.0.0.1:8001`。H5 生产构建需同源反向代理 `/api`，或显式配置完整 API 地址。
- 复制 `.env.example` 到 `.env.local`，使用 `VITE_API_BASE_URL` 指定地址；修改后重新构建。正式发布必须是微信后台配置的 HTTPS 合法域名。
- 小程序保留域名校验。局域网 HTTP 联调需由用户在开发者工具开启相应开发调试选项；正式发布不可依赖此选项。
- 小程序调用 `wx.login`，由现有后端完成微信身份交换。H5 本地联调使用开发 code，后端必须显式开启 `DEV_LOGIN=1`；生产禁止。

主机启动现有后端可使用 `make dev-server`。启动前先确认数据库和运行中的服务，避免重复占用 8001。真实微信配置和模型凭据只放服务端，前端不存放任何 API 密钥。

## 真实功能

| 页面／流程 | 行为 |
|---|---|
| 首屏 | 登录后读取家庭、宝宝及记录；失败显示重试，不填示例数据；未建档显示建档入口 |
| 首页／记录 | 同一份服务端记录，日周月筛选、分类统计、结构化新增、点按编辑、删除和撤销；成功响应后更新列表 |
| 语音／照片 | 真录音／相册／相机 → 上传 → `from-voice/from-photo` 草稿 → 修改 → 确认保存；取消后忽略晚到响应 |
| AI | 真实问答、当前会话、新对话、来源链接、关联记录、语音转写填入输入框；失败保留输入，不生成假回复 |
| 哭声 | 私有用途音频上传、真实五分类／不确定结果、自动保存的历史、AI 解读；重试复用已上传媒体 |
| 成长 | 身高／体重实际测量趋势与时间线；没有虚构的参考曲线或百分位结论 |
| 档案 | 昵称、生日、性别读取／修改；建档／修改遵循家庭管理员权限 |
| 家庭 | 真实成员、邀请码创建／复制／预览／加入／撤销、家庭切换、改名、称呼、角色调整、转交及移除 |
| 导出／设置 | CSV 导出和原始 JSON 记录复制；重新加载数据、账号注销（再次确认） |

本次用户明确选择“仅对接已有后端”。发现页保留原型搜索、分类、专题及主题卡片结构，内容入口明确未开放；头围、里程碑、扩展档案、会员、云收藏、消息、通知偏好及反馈没有对应接口，不伪造数据、成功提示或本地保存替代后端。主题标题不是已发布文章。

旧演示存储 `dongbao.client-v13.v1` 不再读取或写入，也不会自动上传其中的虚构记录。实际业务数据来自后端，不作为全局本地缓存持久化。账号与家庭切换会清除页面数据及待发送输入。

## 复用边界

`src/services/` 与 `src/features/` 是指向旧客户端现有实现的源码转导出入口。API、鉴权重试、领域类型和录音生命周期复用 `apps/client/src`，因此请保留完整仓库，不要单独搬走本目录。`RecordForm.vue` 是本工程的展示组件，业务 payload 类型与校验仍使用共享领域模块。

`src/domain/workspace.ts` 负责真实调用、保存状态、家庭隔离与异步取消；`src/domain/presentation.ts` 负责服务端记录到设计展示的转换。现有客户端及后端用户改动不在本次提交中。

## 验证与边界

- 默认单测包含新工程的状态／数据测试，以及复用的现有会话、登录、HTTP、上传和录音用例。
- `backend.integration.test.ts` 默认跳过，需专门开启；它使用新前端实际 API 封装，通过 HTTP 调用隔离后端，不启动 GUI。
- 2026-10-29 本轮验证：`npm run typecheck`、`npm test`（61 通过，4 项 HTTP 集成测试按配置跳过）、`npm run build:h5` 均通过。
- 本轮未启动 HTTP 集成服务、未运行服务端测试、未调用外部模型，不能据此认定真实 ASR／视觉／大模型或微信登录已验收。
- 后续 HTTP 联调应使用隔离数据库、禁用外部模型的 provider 配置和临时媒体目录，避免影响正在使用的家庭数据。后端 pytest 会清空目标库，不能直接对正在使用的数据库运行。

独立 HTTP 验证服务准备好后：

```bash
DONGBAO_LIVE_API=1 VITE_API_BASE_URL=http://127.0.0.1:8013/api/v1 \
  npm test --prefix apps/client-v13 -- src/domain/backend.integration.test.ts
```

需要用户自行真机确认：微信登录、布局与底栏安全区、键盘／弹窗滚动、相机与麦克风授权、实际上传、剪贴板及真实模型服务输出。本次未进行界面目视或真机验收。

## 本轮原型交互补齐

- 首页与记录页：语音／拍照双卡、四列手动快捷入口、抽屉抓手、类型专属表单；日／周／月标题与实际统计范围一致。
- 更多记录：体温、不适、疫苗、自定义四个入口。体温与不适预填自定义标题，使用现有 `custom` 数据结构保存。
- 哭声页：在原页面开始／停止录制、显示波纹和 30 秒计时，处理失败可重试；离开页面取消等待，后端已保存结果仍可从历史读取。
- 成长页：数据／时间线／里程碑、详细曲线覆盖层、测量记录编辑和新增；里程碑区域保留原型位置并明确未开放。
- 档案与我的：恢复菜单图标、底部插画和原型卡片结构；AI 页恢复副标题，照片草稿保留原图供核对。

与原型的必要差异：使用真实家庭数据替换示例数据；哭声 POST 自动持久化，结果操作显示“查看历史”；没有服务的入口标记未开放；真实字段校验、联网失败与权限错误不能按原型模拟成功。尚未进行像素对照或界面目视确认。
