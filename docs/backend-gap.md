# 后端能力缺口（前端 V1.4 对齐后）

> 前端页面已按青绿色原型 V1.4 铺齐。本文件只列**当前前端还需要后端补的能力**，不重新设计整套后端。

## 1. 懂宝 AI 对话

| 项 | 说明 |
|---|---|
| 使用页面 | 首页入口卡、`pages/ai` |
| 能力 | 结合宝宝档案 + 近期记录 + Qdrant RAG tool 回答 |
| 前端需要 | 已接 `POST /api/v1/ai/chat`；结构化 `ParentingAnswer`；语音→ASR→同一对话框 |
| 当前是否已有接口 | **有**：`/api/v1/ai/chat`、`/conversations/active`、`/conversations/new` |
| 当前是否临时数据 | 否（演示路径已替换）；无 `MODEL_API_KEY` 时走降级卡片仍可检索知识库 |
| 还需要后端补什么 | 图片 / Memory / Langfuse / 睡眠生长工具已接；语料可持续扩充；`make langfuse-up` 本地观测 |

## 2. 哭声分析

| 项 | 说明 |
|---|---|
| 使用页面 | `pages/cry`、`pages/cry/result` |
| 能力 | 上传/录制哭声音频 → 分析结果（可能需求、说明、免责声明） |
| 前端需要 | 上传音频得到 analysis_id；查询结果含标签/建议文案；结果必须可标记为真实或失败，禁止静默假数据 |
| 当前是否已有接口 | 无（仅有普通 `crying` 记录类型） |
| 当前是否临时数据 | 是：本机录音/选文件可预览；分析结果为固定演示 |
| 还需要后端补什么 | 哭声音频上传 + 分析任务 + 结果查询；未就绪时返回明确「未接入」状态 |

## 3. 推荐内容 / 收藏

| 项 | 说明 |
|---|---|
| 使用页面 | 首页推荐、`pages/articles`、`pages/article`、`pages/favorites` |
| 能力 | 按宝宝阶段/记录推荐文章；收藏与取消收藏 |
| 前端需要 | 文章列表（标题、摘要、分类、推荐理由、正文、审核来源）；收藏 CRUD |
| 当前是否已有接口 | 无 |
| 当前是否临时数据 | 是：本地静态 3 篇示例 + `uni` 本机收藏 |
| 还需要后端补什么 | 内容库与推荐接口；用户收藏接口；来源与审核元数据 |

## 4. 维生素 AD 独立记录类型（可选）

| 项 | 说明 |
|---|---|
| 使用页面 | 首页四入口「维生素 AD」 |
| 能力 | 与用药区分的专用类型，便于统计与筛选 |
| 前端需要 | `record_type` 枚举含维生素 AD，或明确约定用 `medication` + 固定 name |

| 还需要后端补什么 | 若产品要独立统计/筛选：新增枚举与 payload；否则保持现状即可 |

## 5. 数据统计专用聚合（可选）

| 项 | 说明 |
|---|---|
| 使用页面 | `pages/stats`、记录页「数据统计」入口 |
| 能力 | 近 7 天趋势、多指标概览 |
| 前端需要 | 按日聚合序列（奶量等）；或继续用记录列表前端聚合 |
| 当前是否已有接口 | 仅有 `GET .../daily-summary`（单日） |

| 还需要后端补什么 | 可选 `GET .../stats/range?from&to`；无则前端聚合可继续 |

## 6. 退出登录（服务端）

| 项 | 说明 |
|---|---|
| 使用页面 | 「我的」→ 退出登录 |
| 能力 | 结束本机会话；**不删除**宝宝档案与数据 |
| 前端需要 | 清本地 JWT 即可；若需服务端吊销则要 logout/黑名单 |
| 当前是否已有接口 | 无（JWT 无状态；前端 `clearCredentials`） |
| 当前是否临时数据 | 否：本地清凭证后可静默重登 |
| 还需要后端补什么 | 当前方案足够；若要强制吊销未过期 token 再补 |

## 7. 宝宝生日可空（已补最小改动）

| 项 | 说明 |
|---|---|
| 使用页面 | 软建档、宝宝档案编辑 |
| 能力 | 登录直进首页；默认昵称「宝宝」；生日可稍后补充 |
| 前端需要 | `birth_date` 可为 null |
| 当前是否已有接口 | 已放宽：`BabyCreate.birth_date` 可选；迁移 `0003_baby_birth_date_optional` |
| 当前是否临时数据 | 否：无宝宝时前端静默 `POST /babies`（昵称宝宝、生日 null） |
| 还需要后端补什么 | 可选：登录时服务端自动建默认宝宝，减少客户端静默建档 |
