# 懂宝 1.3 前端对接范围

状态：用户已确认范围 A；验收 B 仅限已下载、本地执行且不计费的模型。2026-10-29 继续实施。

## 用户已明确的目标

- 新增独立前端工程，微信小程序为主。
- 页面结构、视觉和交互以 `dongbao-interactive-prototype1.3.html` 为依据。
- 必须调用真实后端，不能以固定演示回复、本地记录或模拟成功替代服务端功能。
- 沿用已建立的 `apps/client-v13` 作为新工程，不覆盖现有客户端及用户未提交改动。
- 前端验证限类型检查、单元测试、构建和源码审查，不由 Agent 操控任何 GUI。

## 已核实的接口边界

| 原型能力 | 现有后端能力 | 实施约束 |
|---|---|---|
| 登录 | 微信 code 换服务端凭证 | 复用现有鉴权逻辑，服务端验证身份 |
| 宝宝档案 | 昵称、生日、性别 | 扩展档案需新增接口，不能声称本地保存等于服务端保存 |
| 日常记录 | 增删改、恢复、列表、日汇总 | 按类型提交结构化字段，成功后以服务端结果更新页面 |
| 语音／拍照 | 媒体上传、from-voice/from-photo、confirm | 与原型一致，识别得到草稿，用户确认才成为记录 |
| 快速采集 | capture/reply 可能自动保存 | 不与需要确认的草稿链混用 |
| AI 对话 | chat、当前会话、创建会话 | 展示实际答复、来源与错误，不伪造回复 |
| 哭声分析 | 创建、列表、详情、删除、解释 | 五分类；允许不确定；分析创建即持久化，不能再伪造一次日常记录保存 |
| 生长数据 | 身高、体重记录 | 没有头围字段，也没有标准百分位计算接口 |
| 家庭 | 成员、邀请、加入、切换、权限管理等 | 遵循当前用户的家庭范围与角色权限 |
| 其他 | 未见扩展档案、里程碑、文章、收藏、设置、通知、会员、反馈接口 | 需由用户决定本次补后端还是明确暂不可用 |

代码依据：`apps/server/app/main.py`、`record/routes.py`、`record/schemas.py`、`record/capture.py`、`ai/routes.py`、`cry/routes.py`、`cry/schemas.py`、`family/routes.py`；现有请求封装见 `apps/client/src/services/api.ts`。
