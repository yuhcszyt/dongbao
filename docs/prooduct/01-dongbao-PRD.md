# 懂宝｜PRD

> 版本：v1.1\
> 产品范围：Phase 1～5

## 1. 产品定位

懂宝是一款面向 0～6 岁婴幼儿家庭的 AI 育儿助手。

核心定位：

> **以宝宝长期数据为上下文的 AI 育儿助手。**

四个已确定核心能力：

1.  记录宝宝
2.  懂宝 AI
3.  哭声识别与解释
4.  主动信息推送

第五阶段解决多用户、数据隔离与家庭共享。

## 2. 用户价值

用户逐渐形成：

``` text
有事情 → 记录
有问题 → 问懂宝
宝宝哭 → 用哭声监测
不知道该关注什么 → 看懂宝推荐 / 提醒
```

最终体验：

> 记录宝宝 → 理解宝宝 → 回答问题 → 主动陪伴

## 3. 目标用户

-   新生儿家庭
-   0～3 岁宝宝父母
-   爷爷奶奶、外公外婆等照护者
-   需要共同记录宝宝成长数据的家庭

记录模块必须适老： - 大按钮、大文字 - 支持语音 - 支持拍照 -
不依赖长按或复杂手势 - 默认当前时间 - AI 识别后先确认 - 支持修改和撤销

## 4. 一级导航

``` text
首页
记录
懂宝 AI
我的
```

首页第一目标是快速知道"宝宝现在怎么样"，而不是展示功能菜单。

## 5. Phase 1：AI 辅助记录

### 目标

通过手动、语音和图片低成本沉淀真实宝宝数据；语音/图片由 AI 自动理解并生成可确认草稿，为后续 Agent 提供高质量上下文。

### P0

-   宝宝建档
-   手动/快捷记录
-   语音记录 + ASR
-   拍照记录 + Vision
-   结构化信息提取
-   RecordDraft
-   确认保存
-   时间线
-   修改、删除、撤销
-   今日奶量、睡眠、尿布、辅食基础汇总

记录类型：喂奶、辅食、睡眠、排便、尿布、哭闹、身高体重、疫苗、用药、自定义事件。

阶段边界：Phase 1 即接入 ASR、Vision 与结构化信息提取。AI 只能把语音/图片理解结果预填为 `RecordDraft`，必须由用户确认后才能写入正式宝宝记录；识别失败时允许退回手动补充。Phase 1 不引入完整 Agent Loop、RAG、长期 Memory 或 Tool Calling。

## 6. Phase 2：AI Agent

### 目标

在 Phase 1 已具备多模态识别能力的基础上，让 AI 围绕“当前宝宝”进行上下文问答、记忆与工具调用。

### P0

-   AI 对话
-   文字、语音、图片输入
-   宝宝档案上下文
-   近期记录上下文
-   Tool Calling
-   基础 RAG
-   专业来源
-   结构化回答
-   历史会话

语音/图片问题复用 Phase 1 已建立的 ASR / Vision 基础能力；Phase 2 的新增重点是 Agent、Context、Memory、Tool Calling 与 RAG，而不是再次建设记录识别链路。

推荐回答结构：

``` text
结论
为什么这么判断
结合宝宝当前情况
现在可以怎么做
需要观察什么
专业来源
```

## 7. Phase 3：哭声识别

### P0

-   实时录音
-   上传音频
-   音频质量检查
-   音频预处理
-   哭声模型推理
-   结构化结果
-   AI 二次解释
-   结合近期宝宝记录
-   最近分析

结果不得包装成绝对医学结论，不展示未经验证的伪精确概率。

## 8. Phase 4：信息推送

### P0

-   记录提醒
-   成长阶段提醒
-   疫苗/体检提醒
-   数据变化提醒
-   育儿文章推荐
-   消息中心
-   Push 开关
-   免打扰

原则：少而有价值，不制造焦虑，不重复轰炸。

## 9. Phase 5：多用户 / 家庭共享

### P0

-   用户登录
-   Family
-   Family Member
-   邀请
-   家庭角色
-   共享宝宝
-   成员记录来源
-   数据隔离
-   成员移除
-   基础审计

## 10. AI 产品原则

-   明确当前宝宝
-   优先结构化卡片
-   引用真实宝宝记录
-   专业知识展示来源
-   数据不足就明确说明
-   不虚构记录和来源
-   不冒充医生
-   危险信号优先提示就医

## 11. 推荐原则

``` text
宝宝客观信息
>
当前成长阶段
>
近期记录变化
>
近期咨询问题
>
文章阅读行为
```

用户侧表达："根据宝宝当前情况为你推荐"。

## 12. 视觉原则

温暖、干净、柔和、专业、轻量、可信、有陪伴感。

避免医院系统、企业 SaaS、传统母婴商城、过度卡通、满屏粉色和普通 ChatGPT
套壳。

## 13. 非目标

当前不做： - 微服务 - 复杂 RBAC - 独立向量数据库 - 医生在线问诊 -
智能硬件 - 自动医学诊断 - AI 未经确认自动写业务记录
