# 哭声识别验收记录（2026-09-26）

验收对象：`f009528 feat(cry): add real five-class audio analysis`。结论：**本地自动化检查通过，按 `docs/design/03-cry-analysis.md` 的功能验收未通过**。本记录没有进行 GUI、真机、线上服务或真实宝宝哭声的验证。

## 已验证

- `make test`：服务端 77 个测试通过；客户端类型检查和 96 个测试通过。测试使用本地 `postgres-test`，未重建服务镜像。
- `cd apps/client && npm run build:h5`：构建通过。
- 本地模型文件可加载；使用临时生成的 2 秒 440 Hz 合成音调用 `classify_audio()`，完整走过 FFmpeg 质量检查和五分类推理。
- 源码和测试确认：上传接口检查文件类型、大小和时长；分析接口按家庭和宝宝校验音频；私有哭声音频不能通过公开媒体 URL 读取，设有七天到期清理；结果包含模型标识、五个候选和非诊断说明。

## 阻塞项

1. **非哭声会得到看似确定的原因。** 纯 440 Hz 合成音被分类为“腹部不适”，声音匹配度 87.1481%。`apps/server/app/cry/classifier.py` 的质量门槛只检查长度和音量；五分类模型没有“非哭声”类别。与规格中“非哭声音频 → 提示无法有效分析”不符。该分数只是在五类中的模型输出，不能作为真实原因或模型准确率。
2. **本机历史没有账号隔离。** `apps/client/src/features/content/cryAnalysis.ts` 把最近结果保存在固定键 `dongbao.cry.analyses.v1`；`apps/client/src/features/record/store.ts` 的退出和注销流程没有清除此键，结果页还会默认显示本机历史首项。另一账号在同一设备登录后可能看到前一账号的哭声分析内容。
3. **“结合记录问懂宝”没有带入分析结果。** `apps/client/src/pages/cry/result.vue` 的按钮仅切换到 AI tab，未传入候选结果或宝宝近期记录。规格要求的结合记录解释及“无近期记录”的处理尚未落地。

## 范围差距与待人工确认

- 历史记录目前只在本机保存最近十条结果，服务端没有 `cry_analysis` 持久化和结果查询接口；因此无法跨设备回看或在模型不可用后复用已上传音频重试。
- 根据仓库约束，没有打开浏览器、微信开发者工具或任何 GUI。请由用户在目标微信小程序上确认：麦克风权限、开始/停止录音、音频上传、分析中与报错状态、五个候选同时展示、返回和历史回看。
- 没有用真实哭声样本评估分类质量，也没有验证线上部署、HTTPS、微信后台配置或真机网络链路。以上均不能由本地测试通过来替代。
